# Pink Weather Dashboard 💗💜

A responsive weather dashboard built with HTML, CSS and JavaScript. It uses the OpenWeatherMap API to retrieve current weather conditions for cities around the world.

## Features

- Search for weather by city.
- Display temperature in Celsius.
- View weather conditions, feels-like temperature, humidity, wind speed and pressure.
- Loading and error messages.
- Save the last five searches using localStorage.
- Click previous searches to view their weather again.
- Responsive design for mobile and desktop.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Promises and async/await
- OpenWeatherMap API
- localStorage
- GitHub Actions and GitHub Pages

## Setup

1. Clone this repository.
2. Create a `config.js` file in the project root.
3. Add your OpenWeatherMap API key:

   `const API_KEY = "YOUR_API_KEY_HERE";`

4. Open `index.html` in a browser using a local development server.
